Localized content migration

22,386 regional URLs are imported with the same import scripts as www (same templates, same markup). Per-site effort is run + remediation of regional-only pages (SAPAC 949, EMEA 1,560, JP 1,796, CN 1,026, KR 656) and locale metadata. Pages missing in a region (e.g. 1,960 www paths absent in China) are not created; hreflang lists only real equivalents.

Translation & localization

Japanese and Korean pages are machine translations of English with a disclaimer; Chinese pages are localized. Existing translations are migrated, not re-translated. Translation effort covers: (1) a translation workflow in EDS (build once: MT/translation-vendor connector or export/import, MT-disclaimer flag in metadata), (2) UI strings / placeholders per language (nav, footer, block labels, search, forms, dates; ~400–500 strings), (3) linguistic QA on a sample (~5% of pages per language), (4) CJK typography and font hosting. Full human re-translation is excluded (see Assumptions).

Migration automation

Two parser sets (Core Components; legacy Bootstrap). No bot protection was encountered, so page extraction works; an AEM content export (JCR packages or Assets API) is preferred for structured fields (dates, tags, Facet meta) and for China (separate farm).

Assets and documents

Images come from assets.illumina.com and Dynamic Media (/is/image); PDP pages link up to 58 PDFs each. Images used in pages move into EDS media; PDFs stay in DAM/CDN with stable URLs (recommended) to avoid re-linking from external sites.

Search

Site search is a Google Custom Search proxy (/bin/goose, /bin/suggestions, search-terms-200.json), with Vertex in progress. Support search redirects to it. EDS: serverless proxy + search block; China needs a non-Google provider (Google is not reachable in mainland China).

Forms

Pardot iframes with prospect prefill (/bin/pardot/getprospect), reCAPTCHA, Informatica email verification; a few legacy Marketo forms; Veeva MedComms for medical inquiries. 11 form pages per site.

Authentication

Marketing is public. MyIllumina profile/cart calls run for every visitor (401 when anonymous). OIDC (login.illumina.com) protects a small number of secured paths per the inventory; EDS needs edge auth only if those paths stay on the marketing site.

Analytics, tags and personalization

Launch (China: assets.adoberesources.cn), ACDL data layer, Adobe Analytics + SAINT, GTM (not in China), Target/AEP Web SDK + Recs feed, Salesforce MCP/Evergage, ContentSquare, Qualtrics, ZoomInfo, Reddit, chinalytics, Baidu. EDS loads tags in the delayed phase; the data layer is rebuilt from page metadata.

Consent

OneTrust on all six sites (also China), domain scripts per domain, categories C0002–C0005 gate analytics, social and Evergage.

SEO and redirects

  • Canonical: missing on 59/59 sampled pages — add globally.
  • hreflang: only in sitemaps; invalid codes jp, cn alongside ja-jp, zh-cn; 25–30 alternates per URL incl. en-xx country codes for SAPAC/EMEA. Generate from the locale map in EDS (head + sitemap).
  • Structured data: none today; add Organization, Product, Article, Event, VideoObject.
  • Redirects: ~7% of sitemap URLs (≈1,900 across six sites) are 301/302/404; plus legacy → EDS path changes. Redirect sheet per site.
  • Sitemaps: per locale, generated by EDS.

Performance

Sampled pages average 383 KB of HTML, 68 images and 25 scripts; nav markup alone is ~800 elements per page; jQuery + Bootstrap + React load on legacy pages; 8–12 font 404s per page. EDS three-phase loading, a lighter nav and responsive images will improve LCP/TBT substantially.

Accessibility

16 of 59 sampled pages have zero or multiple H1s; modals, mega-nav and facet filters need keyboard and ARIA work. Target WCAG 2.1 AA at block level, with an audit before launch.

Japan

Same templates. Region-specific items: MT disclaimer (global and footer), Japan campaign folders /destination/ and /on-domain/ (outside the sitemap, volume unknown), links to illuminakk.co.jp iSchool/iAcademy, JP social accounts, CJK fonts (currently CORS-blocked from www).

China

Same templates; different delivery. The supplied architecture diagram shows a separate China publisher/dispatcher farm. EDS has no mainland China edge, so the China site needs an in-China CDN/origin (e.g. China CDN partner fronting EDS or a mirrored origin) under the existing ICP licence. Also: China Launch CDN, no Google services (GTM, CSE, reCAPTCHA, YouTube, fonts), Youku video, Weibo/WeChat, components.illumina.com.cn and api.prd-web.illumina.com.cn, chinalytics/Baidu.

Validation

Automated completeness scoring of every imported page (source vs EDS text/link/image counts), visual critique of a sample per template per locale, redirect verification, tag validation per report suite.

Deployment

Five domain cutovers (www incl. /ko-kr, SAPAC, EMEA, JP, CN) behind the existing Route 53 / CloudFront / WAF stack (diagram) or a BYO-CDN configuration; China cutover last.
