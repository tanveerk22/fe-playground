Localized content migration

11,280 JP/CN/KR URLs are imported with the same scripts. Regional-only paths: JP 566, CN 472, KR 158. Aliases (SAPAC/EMEA) are not migrated.

Translation & localization

JP and KR are machine translations (disclaimer present); CN is localized. Existing content is migrated, not re-translated. Effort: translation workflow (shared design with marketing), UI strings per language (~300 strings: nav, tabs, listing filters, downloads labels), linguistic QA on ~5% of pages, CJK typography.

Migration automation

Markup is very regular (one legacy generation), so a single parser set covers ~95% of pages. Download detail and tab pages are fully automatable.

Assets and documents

Support is document-heavy: PDFs, sample sheets, installers (via SWD), e-learning packages under /content/dam/illumina-support/courses/. Keep files in DAM/CDN at stable URLs; migrate pages only.

Search

Support search hands off to www search (shared Google CSE). Listings use /bin/search/documents.json; EDS replaces this with query indexes per locale.

Forms

Few forms (contact me, auth validation); Pardot + reCAPTCHA.

Authentication

PSP documentation and patches (136 primary, 268 incl. regions) redirect to login.illumina.com (OIDC). Options: (a) keep these paths on AEM and route by path at the CDN, (b) EDS + edge authentication worker validating the OIDC session. Estimate assumes (b); (a) reduces effort but keeps AEM running.

Analytics and tags

Launch + ACDL, Adobe Analytics, GTM (not CN), AEP Web SDK, Evergage, Qualtrics, ZoomInfo, Reddit. Loaded in the delayed phase.

Consent

OneTrust on all hosts including China.

SEO and redirects

  • Canonical: 1 of 48 sampled pages — and three hosts serve identical content (alias duplication). Fix with canonicals + alias 301s.
  • hreflang: sitemap-only, invalid jp/cn codes.
  • Redirect maps: 249 bulletins → KB, 63 FAQ → support-docs, alias hosts, retired product pages.

Performance

Average 341 KB HTML, 55 images, 21 scripts; jQuery Migrate, Bootstrap 4, Font Awesome Pro (CORS-failing). EDS will cut payload significantly.

Accessibility

14 of 48 sampled pages have zero or multiple H1s; collapsible file groups and modals need keyboard support.

Japan

Same templates; MT disclaimer; additional JP downloads/training. Minor JP-specific items (legal footer, JP social, training language selectors).

China

Separate China farm; needs in-China delivery for EDS (same approach as marketing). China Launch CDN, no Google services, Youku instead of YouTube, China MyIllumina API host; validate SWD and SAP reachability from China.

Validation

Completeness scoring of every imported page; file-link checks for every download (link rot is the main support risk); redirect verification for bulletins/FAQ/aliases.

Deployment

Cutovers: support.illumina.com (+/ko-kr), JP, CN; alias hosts switched to 301 at the same time as the primary.
