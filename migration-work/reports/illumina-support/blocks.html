EDS block variants

Every one of the 29 Support blocks was checked for variants against the component markers on the 248-page deep sample (85 support pages: en-US 50, ja-JP 11, zh-CN 10, ko-KR 8, aliases 6) plus live checks of the CoA and SDS finder pages. A variant is only counted when the EDS block needs a different style, content model, behaviour or regional configuration. Content-only and language differences are not variants: translated copy, per-locale link lists and legacy-vs-core markup of the same component are handled by content and the import parsers. Variants are priced inside their base block; an estimate changes only where the evidence shows work the base estimate did not include.

Corrections and open points from the variant review

  • Downloads list uses the same literature-list markup as Documentation list (name, size, date, “View Options” for versions). The softwaredownloads.illumina.com iframe is hidden on every download page and is priced as the SWD integration. Downloads becomes a Documentation list variant. Observed
  • Featured tile / interrupter is a grid of card-horizontal cards plus an icon link row: it becomes the Cards (horizontal) and Tools panel (icon row) variants. Observed
  • CoA finder is the existing mi-certificate-document-list micro-frontend; the block hosts it. Loading the MFE is already priced in the integrations (8–16 h), so the block allowance was reduced. Observed
  • SDS finder is a separate Vue app over the SAP servlet /bin/sap/safety/data/system/document: it is not a duplicate of the CoA finder and keeps its estimate. Observed
  • Youku was not found on any China support page; video modals set their source at click time, so the China video provider must be confirmed. Needs validation
  • China support pages are mostly English (text similarity 0.99): this lowers linguistic effort but does not create block variants. Observed
