URLs inventoried were read from sitemaps only. URLs classified were fetched live and their AEM template marker recorded. Pages deeply analyzed had their full HTML, components, integrations, media, forms and SEO tags extracted. Regional comparisons fetched the same path on each regional domain and compared it with the primary.

1 · Sitemap analysis and URL clustering

robots.txt on every support host points to sitemap-amr-support.xml (+ Korean) except Japan and China, which have their own. SAPAC support's own sitemap URL returns a "Page Not Found" HTML page; EMEA support's sitemap is an older format without hreflang. URLs were clustered by section and product type and mapped to EDS templates by path (e.g. /sequencing/sequencing_kits/<product>/documentation → Product Support Tab).

2 · Primary-site selection and stratified sampling

48 primary pages: product hubs (instrument, kit, software, array, clinical), each tab type (documentation, downloads, compatibility, questions), download detail, training, bulletins, PSP, list pages, support content, CoA/SDS tools, search. Browser network capture on downloads, CoA finder and search.

3 · Template discovery (source AEM templates)

Legacy pages expose pageTemplate meta: summarydownloadspage (39% of census), onecolumnpage (21%), rightrailpage (7%), training (5%, configuration records), bootstrap4fullpage, widepage, bootstrapfullpage, supportbasepage, bulletinIndividualItemTemplate, supportlistpage, plus a few modern basicpage-template pages (PSP landing, CoA finder). 12 source templates → 10 EDS templates.

4 · Component and block discovery

Components from parbase names (productSelector, trainingSection, landingPageFeaturedTile, alertBanner, contactUsFooter) and semantic classes (pdp-documentation, resource-card-grid, tools-container, product-drawer-container).

5 · Integration discovery

HTML host scan, browser network capture, the supplied Third-Party Integrations Inventory and architecture diagram. Key discoveries: the SWD iframe on every download page, /bin/search/documents.json, /bin/contact/info (500), the CoA micro-frontend, and the login redirects on PSP.

7 · Saturation

Support is very regular: after ~200 census pages no new source template appeared, and product hubs/tabs repeat the same components. Regional sampling stopped at 24 pairs because aliases were identical and language sites matched from the first pairs.

8 · Estimation methodology

Same model as the marketing report: templates, variants, blocks and integrations estimated once; content migration separated; regional increments itemized; 10% coordination. Non-page URLs (records, redirects) are priced as data conversion and redirect maps, not page migration.
